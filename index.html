주차별 강의 노트

01week 요구 분석 교육문제 정의, 대상 학습자 분석, 요구 도출. 과제를 직접 수행하고 학습자 산출물·교재를 분석해 어디서 막히는지 스스로 찾아냅니다. 산출물요구분석 보고서
공개됨 02week 문헌 분석 AI 에이전트, 교수학습이론, 관련 교육 전략, 기존 시스템 분석. 학술논문과 유사 사례를 비교해 연구의 공백을 찾습니다. 산출물문헌분석표 · 사례분석표
공개됨 03week 설계원리 도출 요구와 문헌을 설계원리로 변환하는 방법. 흩어진 근거를 묶어 검증 가능한 원리와 지침으로 바꿉니다. 산출물설계원리 및 설계지침
공개됨 04week 에이전트 명세서 작성 설계원리에서 기능·행동·상호작용·평가까지 하나로 연결합니다. 역할, 스캐폴딩, 피드백, 보안 정책을 문서로 확정합니다. 산출물agent-design.md
공개됨 05week AI 에이전트 구현 LLM 에이전트의 다섯 부품 — Prompt, State, Tool, Knowledge, Harness. Claude Code와 Codex로 명세서를 코드로 옮깁니다. 산출물Prototype v1
공개됨 06week 전문가 타당화 내용타당도와 설계 타당성. 전문가 평가를 실시해 설계원리·기능·상호작용의 적절성을 검토하고 고칩니다. 산출물타당화 결과 · Prototype v2
공개됨 07week 사용성 평가 사용성·유용성·교육적 적합성을 실제 사용자에게 확인합니다. 대화 로그, 설문, 인터뷰를 함께 읽습니다. 산출물평가 결과 · 최종 Prototype
공개됨 08week 연구 결과 발표 개발 연구 결과를 구조화하고 해석합니다. 연구문제–방법–결과–논의 형식으로 발표하고 에이전트를 시연합니다. 산출물연구보고서 · 발표 · GitHub

일곱 개의 질문

각 주차는 앞뒤가 물린 일곱 개의 질문으로 이루어져 있습니다. 왼쪽 사슬을 따라 위에서 아래로 읽으면 그 주의 산출물이 완성됩니다.

표시

세 가지 상자

파란 상자는 지금 손으로 해볼 것, 붉은 상자는 흔히 빠지는 함정, 점선 상자는 경험이 있는 사람을 위한 추가 과제입니다. 파란 상자 맨 아래 → 줄은 그 결과를 어느 문서 어느 절에 적으라는 뜻입니다.

준비

필요한 것

개발 경험은 없어도 됩니다. 1~4주차는 도구 없이도 진행됩니다. 이 기간의 AI 활용은 선택 사항이고 무료 대화 서비스로 충분합니다. Claude·Codex 유료 구독은 5주차 개발이 시작될 때부터 필요합니다. 설치와 환경 설정은 5주차 부록에 있습니다.

원칙

증거로 말하기

이 수업의 모든 주장에는 근거가 붙습니다. "좋아 보인다" 대신 누가, 어떤 자료에서, 무엇을 관찰했는지를 씁니다.

명세서는 이렇게 자랍니다
