주차별 강의 노트

각 주의 산출물이 다음 주의 재료가 됩니다. 한 주를 건너뛰면 그다음 주에 쓸 것이 없습니다.

01week 요구 분석 교육문제 정의, 대상 학습자 분석, 사용자 요구 분석. 인터뷰·설문을 설계해 실제로 무엇이 안 되고 있는지 확인합니다. 산출물요구분석 보고서
공개됨 02week 문헌 분석 AI 에이전트, 교수학습이론, 관련 교육 전략, 기존 시스템 분석. 학술논문과 유사 사례를 비교해 연구의 공백을 찾습니다. 산출물문헌분석표 · 사례분석표
준비 중 03week 설계원리 도출 요구와 문헌을 설계원리로 변환하는 방법. 흩어진 근거를 묶어 검증 가능한 원리와 지침으로 바꿉니다. 산출물설계원리 및 설계지침
준비 중 04week 에이전트 명세서 작성 설계원리에서 기능·행동·상호작용·평가까지 하나로 연결합니다. 역할, 스캐폴딩, 피드백, 보안 정책을 문서로 확정합니다. 산출물agent-design.md
준비 중 05week AI 에이전트 구현 LLM 에이전트의 다섯 부품 — Prompt, State, Tool, Knowledge, Harness. Claude Code와 Codex로 명세서를 코드로 옮깁니다. 산출물Prototype v1
준비 중 06week 전문가 타당화 내용타당도와 설계 타당성. 전문가 평가를 실시해 설계원리·기능·상호작용의 적절성을 검토하고 고칩니다. 산출물타당화 결과 · Prototype v2
준비 중 07week 사용성 평가 사용성·유용성·교육적 적합성을 실제 사용자에게 확인합니다. 대화 로그, 설문, 인터뷰를 함께 읽습니다. 산출물평가 결과 · 최종 Prototype
준비 중 08week 연구 결과 발표 개발 연구 결과를 구조화하고 해석합니다. 연구문제–방법–결과–논의 형식으로 발표하고 에이전트를 시연합니다. 산출물연구보고서 · 발표 · GitHub
